# Ground truth

`manual_pairs.csv` is the only file in this repository that cannot be regenerated by
running code, which is why it is tracked in git while `data/raw/` and `outputs/` are not.

One row per candidate pair a human has actually ruled on:

| column | meaning |
| --- | --- |
| `ri_a`, `id_a` | first record: infrastructure and its own identifier, verbatim |
| `ri_b`, `id_b` | second record |
| `same_place` | `yes` or `no` — anything else is ignored by the scorer |
| `checked_by` | who decided |
| `evidence` | what settled it: both landing pages, an operator name in common, a publication, a station photo |

Workflow:

1. `python -m ri_harmonize.cli review` writes `outputs/review_sheet.csv` — the
   un-adjudicated candidates, nearest first.
2. Open both landing pages, decide, fill `same_place`, write down what convinced you.
3. Append the completed rows to `manual_pairs.csv`.
4. `python -m ri_harmonize.cli run --offline` re-scores every method against the enlarged
   ground truth.

Record the negatives too. A pair you rejected is as informative as one you accepted, and
without rejections precision cannot be measured at all.
